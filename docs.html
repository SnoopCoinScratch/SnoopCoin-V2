ScratchGems API Documentation

GET /

Returns API version, current server time, user count, and total balance.

GET /users

Returns a list of all registered users.

GET /balances

Returns all user balances.

GET /users/<username>

Returns the balance for a specific user.

GET /verify

Simple verification endpoint to check if the API is live.

GET /transactions

Returns all transactions.

GET /transactions/<username>

Returns transactions involving a specific user.

GET /notifications/<username>

Returns notifications for a specific user.
